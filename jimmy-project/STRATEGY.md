## 2. Monetization Plan (How we get paid)
We need to turn traffic into cash. Since we can't easily integrate Stripe/WeChat Pay directly into a static page yet, we use **Lead Generation** and **Affiliate** models.

### Phase 1: The "Human Premium" (Service Upsell)
*   **Concept:** The app handles 90% of cases. For the 10% hard stuff (hospital visits, police registration, complex travel), they need a human.
*   **Action:** Add a "Hire a Local Fixer" (VIP Service) button.
*   **Flow:** User clicks button -> WhatsApp/Email to Jimmy -> You quote a price (e.g., $50/day remote help, or $200/day guide).

### Phase 2: Affiliate Links (Passive Income)
*   **Concept:** Foreigners need VPNs, eSIMs, and Hotel bookings.
*   **Action:** Add a "Resources" tab with affiliate links (Trip.com, Holafly eSIM, Astrill/ExpressVPN).
*   **Revenue:** ~10-30% commission per sale. (Need you to sign up for affiliate programs later, I will build the slots).
